# FeralPig Manifest Checklist

Use this checklist before finalizing a project milestone, filing decision, or handoff.

## File and naming checks
- [ ] All active files match the naming convention: FeralPig_<Artifact>_v<major.minor>_<YYYYMMDD>.<ext>
- [ ] No random suffix variants remain in the canonical project tree
- [ ] Archive contains only superseded, duplicate, generated-export, or extracted content
- [ ] Root directory is clean and focused on current work

## Folder checks
- [ ] admin contains scripts, index files, naming rules, and manifest records
- [ ] docs contains current protocol, status, and support documents
- [ ] drafts contains active provisional/specification drafts
- [ ] claims contains active claim files
- [ ] figures contains current figures
- [ ] reference_materials contains legal/technical references
- [ ] roadmap contains roadmap and milestones
- [ ] tracker contains the working tracker and tracker templates

## Manifest checks
- [ ] A canonical manifest exists and is current
- [ ] Each active file includes version, date, hash, canonical status, and newest flag
- [ ] Hashes are recorded and match the current file contents
- [ ] Duplicate or superseded files are archived and not treated as active

## Claim and drafting checks
- [ ] Tracker is current and controls the draft
- [ ] Claim count matches the active set rule
- [ ] Dependency chain is valid for all claims
- [ ] Risk flags are logged for §112, enablement, written description, prior art, and regulatory issues
- [ ] New claim revisions are reflected in the tracker in the same session
- [ ] No unresolved blocking risk remains before completion or filing

## Disclosure and legal checks
- [ ] NDA required before outside technical disclosure
- [ ] Inventorship records are settled in writing
- [ ] Patent attorney review is complete before filing or material submission
- [ ] Public-disclosure risk has been assessed against speed
- [ ] Regulatory and deployment issues are flagged separately from patentability

## Final milestone signs
- [ ] Current files match the project state intended for release or filing
- [ ] Archive and active project are clearly separated
- [ ] Human or attorney review has approved the state
- [ ] Final handoff is documented and ready for next work cycle
